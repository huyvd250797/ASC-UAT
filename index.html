ASC-UAT chưa khởi động được

Nếu bạn thấy màn hình này quá vài giây, ứng dụng đã không tải được mã nguồn. Nguyên nhân thường gặp:

  • Deploy nhầm thư mục. Đây là file index.html ở gốc dự án, chỉ dùng cho môi trường phát triển. Bản để deploy nằm trong thư mục dist/. Với Netlify: chỉ kéo thả thư mục dist/, không kéo cả thư mục dự án hay file zip.
  • Đang mở bằng đường dẫn file:// — hãy phục vụ qua HTTP, hoặc dùng bản một file dist/asc-uat-standalone.html.
  • Máy chủ chưa khai báo MIME type cho .js (thường gặp ở IIS nội bộ).
  • Thư mục assets/ chưa được copy lên cùng index.html.

Mở Console của trình duyệt (F12) để xem lỗi cụ thể.
